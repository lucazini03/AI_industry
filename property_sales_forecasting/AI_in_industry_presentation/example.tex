\begin{frame}{Project Objective}

    \begin{itemize}

        \item Predict monthly median house prices using historical property sales data
        \item Data source: \href{https://www.kaggle.com/datasets/htagholdings/property-sales}{Kaggle property sales time series dataset}

        \item Understand which factors drive price dynamics over time

        \item Compare multiple forecasting approaches:
              \begin{itemize}
                  \item Random Forest
                  \item LSTM Neural Networks
                  \item SARIMAX Time Series Models
              \end{itemize}

        \item Investigate unexpected model behaviour and improve the feature space

    \end{itemize}

\end{frame}

%------------------------------------------------
\begin{frame}{Dataset}

    \begin{itemize}

        \item Data source: Kaggle property sales dataset

        \item Time span: 2007 -- 2019

        \item Each observation corresponds to a property sale

        \item Key variables:

              \begin{itemize}
                  \item sale date
                  \item property price
                  \item property type (house / unit)
                  \item number of bedrooms
                  \item postcode
              \end{itemize}

        \item Goal: predict a \textbf{monthly time series of housing prices}

    \end{itemize}

\end{frame}

\begin{frame}{Unexpected Observation}

    Across models we noticed a systematic issue:

    \begin{itemize}

        \item Predictions tended to be \textbf{lower than real prices}

        \item Particularly in recent years

        \item Models captured trends but \textbf{underestimated price growth}

    \end{itemize}

    This raised an important question:

    \begin{center}
        \textbf{Why are prices increasing faster than predicted?}
    \end{center}

\end{frame}

%------------------------------------------------
\begin{frame}{Hypothesis 1: Change in Property Types}

    Possible explanation:

    \begin{itemize}

        \item Houses are more expensive than units

        \item Perhaps recent years saw more houses sold

    \end{itemize}

    Result:

    \begin{itemize}
        \item No major structural change detected
    \end{itemize}

\end{frame}

%------------------------------------------------
\begin{frame}{Hypothesis 2: Geographic Shift}

    Maybe buyers increasingly purchased homes in expensive areas.

    However:

    \begin{itemize}

        \item Premium postcode share remained relatively stable

        \item Does not fully explain price increase

    \end{itemize}

\end{frame}

%------------------------------------------------
\begin{frame}{Remaining Puzzle}

    Key empirical observation:

    \begin{itemize}

        \item Sales volume decreased in later years

        \item Yet prices continued rising

    \end{itemize}

    This contradicts simple supply-demand intuition.

    Therefore:

    \begin{center}
        \textbf{Something outside the dataset may be influencing prices}
    \end{center}

\end{frame}

%------------------------------------------------
\begin{frame}{Introducing Macroeconomic Variables}

    New hypothesis:

    \begin{itemize}

        \item Housing markets are influenced by macroeconomic conditions

        \item Important candidates:

              \begin{itemize}

                  \item mortgage interest rates

                  \item central bank interest rates

                  \item credit availability

              \end{itemize}

    \end{itemize}

    These variables were integrated as \textbf{exogenous features}.

\end{frame}

%------------------------------------------------
\begin{frame}{Macroeconomic Effects}

    Observation:

    \begin{itemize}

        \item Falling mortgage rates increase affordability

        \item Can drive price growth even when demand falls

    \end{itemize}

\end{frame}

%------------------------------------------------
\begin{frame}{Improved Model Performance}

    Including macro variables allows models to:

    \begin{itemize}

        \item better capture long-term dynamics

        \item explain rising prices despite falling sales

        \item reduce systematic underprediction

    \end{itemize}

\end{frame}

\begin{frame}{Key Takeaways}

    \begin{itemize}

        \item Housing prices show strong temporal structure

        \item Sales volume and property characteristics are important predictors

        \item However, \textbf{micro-level data alone is insufficient}

        \item Macroeconomic variables play a crucial role in price dynamics

    \end{itemize}

\end{frame}
